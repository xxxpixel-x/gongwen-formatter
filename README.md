# gongwen-formatter 公文格式整理器

用文字写下格式要求，再选择一份格式混乱的 Word 原稿，程序会按要求自动排好版，输出一份新文件。原稿不会被修改。

![界面截图](docs/screenshot.png)

## 使用方法

1. **填写格式要求**，有两种方式：
   - **手动写**：每行写一类段落，格式是“段落类型 + 格式”。输入框里默认已经填好规范要求，可以直接修改。
   - **从模板读取**：点“从模板读取…”，选一份已经排好版的公文，程序会读出它每类段落的字体、字号、行距、缩进和页边距，自动写成格式要求填进输入框。模板里格式不统一的地方，会用 `#` 开头的说明行标出。

   下方表格会实时显示程序理解成了什么，看不懂的部分会用红字标出，不会悄悄忽略。
2. **选择原稿**（.docx）：右侧只列出程序拿不准的段落（黄色卡片），每张卡片显示这段文字和它的上一段。识别对了就点“✓ 对的”，不对就在“这一段是”下拉框里选正确的类型，卡片会变成绿色。如果发现其他段落也排错了，勾选“显示全部段落”即可修改。卡片上方会列出层级序号的检查结果（见下文“层级序号检查”）。
3. **生成排版文件**：默认保存为“原稿名_已排版.docx”。

格式要求会自动保存，下次打开时还在。也可以用“另存txt…”把当前要求保存成文本文件备份。

图形界面、命令行和 `format_file` 接口都禁止把原稿本身（包括指向原稿的链接）作为输出文件。保存时先写完临时文件再替换目标；如果写入失败或文件被占用，已有输出文件会保留。

### 格式要求的写法

```
标题（方正小标宋_GBK，二号，居中）
正文（仿宋_GB2312，三号，英文、数字Times New Roman）首行缩进2字符，行距固定值28磅，两端对齐
一级标题（黑体，三号，顶格）
二级标题：楷体_GB2312 三号 加粗 首行缩进2字符
四级标题（仿宋_GB2312，三号，首行缩进2字符）
页边距：上3.7厘米，下3.5厘米，左2.8厘米，右2.6厘米
页眉1.5厘米，页脚2.8厘米
```

字体名要和电脑上安装的字体名完全一致，中间不能有空格：写 `楷体_GB2312`，不要写“楷体 GB2312”。

| 可写的项目 | 例子 |
|---|---|
| 段落类型 | 标题、副标题、一级标题、二级标题、三级标题、四级标题、五级标题、正文、附件、附件名称、落款、日期 |
| 字体 | 仿宋_GB2312、方正小标宋_GBK、黑体、楷体_GB2312、宋体…… |
| 字号 | 二号、三号、小四……，或 16磅 |
| 加粗 | 加粗 / 不加粗 |
| 对齐 | 居中、两端对齐、左对齐、右对齐 |
| 缩进 | 首行缩进2字符、顶格、右缩进1字符 |
| 行距 | 行距固定值28磅（可带小数，如28.8磅）、1.5倍行距、单倍行距；段前0.5行、段后6磅 |
| 西文字体 | 英文、数字：Times New Roman |
| 页边距 | 上37毫米，下35毫米，左28毫米，右26毫米（也可以用厘米） |
| 页眉页脚 | 页眉1.5厘米，页脚2.8厘米（距页面边界；不写则用 Word 默认值） |

没有写到的段落类型和格式项，沿用默认要求（规范图片）；行距没写时，沿用正文的行距；四级、五级标题没写时与正文相同。以 `#` 开头的行是说明，不影响排版。

### 自动识别规则

| 原稿里的样子 | 识别为 |
|---|---|
| 第一段 | 标题 |
| 第二段较短、不以标点结尾 | 副标题（需要确认） |
| 一、 二、 | 一级标题 |
| （一） （二） | 短标题识别为二级标题；完整句子、过长或界限不清的段落先按正文处理并提示确认 |
| 1. 2. | 三级标题（有明确短标题时加粗到首个冒号；否则只加粗编号） |
| （1） （2） | 四级标题（标题格式的范围同三级标题） |
| 1） 2） | 五级标题（同上） |
| 没有编号的短行，后面接正文 | 一级标题（需要确认） |
| 附件： 及其下面的 1. 2. | 附件、附件名称 |
| xxxx年xx月xx日 及其上方的短行 | 日期、落款 |

**二级编号不一定是标题**：例如“（一）本规划是部门未来三年发展的行动纲领，全体人员须统一思想、坚定信心、真抓实干。”会按正文排版，不会整段套用楷体加粗。独立短标题（如“（一）工作目标”）仍按二级标题处理；“（一）工作目标。正文……”和“（一）工作目标：正文……”只对短标题部分使用标题格式，并提示确认分界。

识别只依据文字：标题候选暂以 30 字（不含编号）为上限；带段尾句号的短标题、较长标题，以及句号/冒号前含逗号的复杂标题，也可能先按正文处理。这些段落会显示在黄色待确认卡片中，确认是标题时可手动选择“二级标题”。命令行 `--check` 会以 `?` 和说明标出需要复核的段落。

冒号出现在时间或比例中（如 `9:30`、`1：2`）时，不作为标题分界；三至五级标题也不会一直加粗到后面正文里的冒号。“附件材料请按时报送。”这类正文不会开启附件区，只有“附件”“附件1”“附件：……”等明确标识才会。

另外，程序会删除多余的空行、行首空格，以及两个汉字之间误输入的空格，并在附件前、落款前各留一个空行。

**层级序号检查**：序号应依次为 一、→（一）→1.→（1）→1）。程序会把写法不标准的编号自动统一（如“1、”→“1.”、半角括号“(1)”→“（1）”、“（一）、”→“（一）”），并提醒两类问题：跳级混用（如“一、”下面直接用“1.”）和编号不连续（如“一、”之后是“三、”）。这两类问题只提醒，不自动改，需要在原稿里改正。

被识别为正文的编号条目仍参与连续性检查，避免误报跳号。“1、2026年重点工作”会统一为“1. 2026年重点工作”，保留分隔空格以免与小数混淆。

## 下载安装

到 [Releases](../../releases) 下载“公文格式整理器-安装包-x.y.z.exe”，双击后按安装向导操作：

1. 欢迎页，点“下一步”
2. 选择安装位置：默认装在当前用户目录下（`C:\Users\用户名\AppData\Local\Programs\GongwenFormatter`），可以点“浏览”改到其他磁盘
3. 确认后开始安装

安装不需要管理员权限，装好后桌面上会出现“公文格式整理器”快捷方式。升级时直接安装新版即可，会覆盖旧版。

如果不想安装，也可以下载“公文格式整理器-免安装版-x.y.z.zip”，解压后双击 `GongwenFormatter.exe` 运行（这种方式不会创建桌面快捷方式）。

**字体**：程序使用的字体需要提前安装在电脑上，例如方正小标宋_GBK、仿宋_GB2312、楷体_GB2312。如果缺少字体，界面会给出提示。方正字体是商业字体，本项目不附带字体文件。

## 当前限制

- 只支持 .docx 格式，.doc 和 .wps 需要先另存为 .docx
- 正文段落中的图片会被跳过并提醒；表格保留原内容和直接格式，其中的图片、外部超链接也会保留；依赖原稿自定义样式的表格外观可能变化
- 表格中的图表、嵌入文档等暂不支持；遇到无法完整保存的资源时，会中止输出并说明原因
- Word 自动编号生成的“一、”“1.”无法识别，程序会给出提醒（包括从段落样式继承的编号）

## 开发

```bash
pip install -e ".[dev]"
pytest                 # 运行测试
python app.py          # 打开图形界面
gongwen-fmt 原稿.docx -r 要求.txt --check   # 命令行版
build.bat              # Windows 本地打包
```

推送 `v*` 格式的 tag（如 `v0.5.0`）后，GitHub Actions 会自动在 Windows 上测试、打包，并把安装包发布到 Releases。
